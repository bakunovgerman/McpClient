# Changelog

Все значимые изменения в этом проекте будут документированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
и проект следует [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-02-01

### Added
- Первый публичный релиз
- Поддержка Model Context Protocol (MCP)
- HTTP/HTTPS транспорт для подключения к MCP серверам
- Полная поддержка JSON-RPC 2.0
- Работа с инструментами (Tools)
- Работа с ресурсами (Resources)
- Работа с промптами (Prompts)
- Асинхронная работа через Kotlin Coroutines
- Batch операции для параллельного выполнения запросов
- Утилиты для работы с конфигурацией
- Интерактивный CLI
- Подробное логирование
- Примеры использования
- Публикация через JitPack
- Поддержка Maven Central (требует настройки)

### Features
- `McpClient` - основной клиент для работы с MCP
- `McpConfig` - конфигурация клиента
- `McpUtils` - утилиты для работы с конфигурационными файлами
- `McpClientFactory` - фабрика для создания клиентов
- Поддержка пользовательских HTTP заголовков
- Обработка ошибок через исключения
- Настраиваемое логирование

### Documentation
- README.md с примерами использования
- PUBLISHING.md - руководство по публикации
- ANDROID_USAGE.md - использование в Android проектах
- EXAMPLES.md - расширенные примеры
- GETTING_STARTED.md - быстрый старт
- ARCHITECTURE.md - архитектура проекта

## Формат версий

Версии следуют формату MAJOR.MINOR.PATCH:
- **MAJOR** - несовместимые изменения API
- **MINOR** - новая функциональность с обратной совместимостью
- **PATCH** - исправления ошибок

## Типы изменений

- **Added** - новая функциональность
- **Changed** - изменения в существующей функциональности
- **Deprecated** - функциональность, которая будет удалена
- **Removed** - удаленная функциональность
- **Fixed** - исправления ошибок
- **Security** - исправления уязвимостей
